CEO ของ Anthropic เคยให้([สัมภาษณ์](https://x.com/rohanpaul_ai/status/2055841486714147177))เอาไว้ว่า
"ซอฟต์แวร์จะถูกลงจนถึงกลายเป็นของฟรี"

การที่เราคิดต้นทุนของซอฟต์แวร์จากจำนวนผู้ใช้หลายล้านคนได้กำลังจะหายไป และในขณะเดียวกัน อาชีพจำนวนมากที่ถูกสร้างขึ้นมาในหลายสิบปีที่ผ่านมาก็กำลังถูกทำให้หายไป

แต่พวกเราจะรับมือกับมันได้ เราจะปรับตัว แต่แค่ตอนนี้แทบยังไม่มีใครตระหนักเลยว่าอะไรกำลังจะเกิดขึ้น
และผลกระทบของมันจะใหญ่ขนาดไหน

> "Software is going to become cheap, maybe essentially free.
>
> The premise that you need to amortize a piece of software you build across
> millions of users, that may start to be false.
>
> But at the same time, there are whole jobs,
> whole careers that we've built for decades that may not be present.
>
> And, you know, I think we can deal with it.
> I think we can adjust to it. But I don't,
> I don't think there's an awareness at all of what,
> of what is coming here and the magnitude of it."

-----------

ครึ่งแรกของคำพูดกำลังเกิดขึ้นจริง

ยังไม่รู้เหมือนกันว่าผู้ให้บริการระบบปฏิบัติการทั้งในคอมพิวเตอร์และมือถือจะปรับตัวไปทางไหน ในแง่ของการให้บริการและภาพรวมของซอฟต์แวร์สำหรับใช้งานคนเดียว
แต่เราคาดการณ์ได้ว่าราคาของซอฟต์แวร์หลายอย่างจะถูกลงจนถึงกลายเป็นของฟรีแน่นอน

สิ่งที่น่าสนใจกว่าคือครึ่งหลังของคำพูด ที่ว่าหลายอาชีพจะหายไป ที่ก็เชื่อได้ว่ากำลังเกิดขึ้นจริงเหมือนกัน

ซอฟต์แวร์ที่ทำงานได้ด้วยตัวเองอาจมีต้นทุนลดลงจนแทบเป็นศูนย์
แต่เชื่อว่าซอฟต์แวร์ที่ต้องเชื่อมต่อกับระบบอื่นจะมีราคาแพงขึ้น
โดยเฉพาะเมื่อ AI Agent สามารถเข้าถึงข้อมูล เรียกใช้บริการ และดำเนินการข้ามหลายระบบได้ด้วยตัวเอง

ความสามารถในการ Integration ที่มากขึ้นของ AI Agent หมายถึงพื้นที่ความเสี่ยงที่กว้างขึ้น
และความผิดพลาดเพียงจุดเดียวอาจส่งผลต่อระบบอื่นต่อเนื่องกันเป็นวงกว้าง
การเชื่อมต่อระบบจึงต้องลงทุนมากขึ้นกับการออกแบบสิทธิ์ การแยกระบบ การตรวจสอบ การกำกับดูแล
และกลไกควบคุมการทำงานของทั้งมนุษย์และ AI Agent

ตัวอย่างเช่น
- ซอฟต์แวร์ฐานข้อมูลทุกอัน
- Public Facing API ทุกที่
- แบบฟอร์มติดต่อสอบถาม
- ซอฟต์แวร์ที่เก็บข้อมูลส่วนบุคคล

ตัวอย่างที่ยกมาต้องเพิ่มกลไกในการควบคุมการเข้าใช้งานและป้องกันการเข้าถึงโดยไม่ได้รับอนุญาตจาก
AI Agent ทั้งหมด การออกแบบระบบให้ซอฟต์แวร์ทำงานร่วมกันจะแพงขึ้น
เพราะราคาที่เราต้องจ่ายเมื่อเกิดความผิดพลาดแพงขึ้น

ผมเชื่อว่าอาชีพเกิดใหม่จะอยู่ตรงนี้แหละ การสร้างซอฟต์แวร์ที่สามารถป้องกันระบบจาก AI Agent
และการทำให้ลูกค้าเชื่อใจให้ได้ว่าซอฟต์แวร์ที่เราขายปลอดภัยพอ
